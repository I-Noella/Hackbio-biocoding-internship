# Hackbio-bio coding-internship
Stage Zero Task - Hackbio Coding Internship

Project Description

This is a Stage Zero task in the Hackbio Coding Internship. The task is to use a data structure of choice to organize my personal information.

I chose a dictionary, which allows me to store my details in key-value pairs. I named the dictionary my_details, which holds the following keys: Name, Slack username, Email, Hobby, Country, Discipline, and Preferred programming language.

Printing my_details explicitly returns all of my details in a structured key-value format.
